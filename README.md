# Number Guessing Game 🎯

A simple and interactive console-based Number Guessing Game built in Java.

## 📖 How It Works

1. The game selects a random secret number between **1** and **100**.
2. You enter your guess into the console.
3. The game provides feedback on each attempt:
   - **Too low! Try a higher number.**
   - **Too high! Try a lower number.**
   - **Congratulations!** when you guess the exact number.
4. The game displays the total number of attempts upon winning.
5. Invalid input (non-numbers or numbers outside 1–100) is gracefully handled with friendly error messages.

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher installed on your system.

### How to Run

1. Open your terminal or command prompt in the project directory.
2. Compile the Java source file:
   ```bash
   javac NumberGuessingGame.java
   ```
3. Run the compiled program:
   ```bash
   java NumberGuessingGame
   ```
